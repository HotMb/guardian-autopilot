# Monetization hypotheses

Free: unlimited local reports, conservative reversible cleanup, CLI/Claude integration.
Pro (test price €19/month): hosted GitHub audits, scheduled reports, multi-repo history and automated pull requests.
Team (test price €79/month): collaborators, shared policies, audit exports and team dashboards.

No one is paid by GitHub per installation. GitHub is the distribution channel; Stripe and eventually GitHub Marketplace are possible billing rails. Validate terms and platform eligibility before publishing paid integrations.

## Validation plan
20 problem interviews -> 10 real consented codebase audits -> 3-5 paid pilot customers. Measure issues validated, false positives, safely accepted PRs, developer hours saved, repeat weekly use and conversion. Avoid measuring value by file count deleted.

## Unit economics
Track support and hosting expenses, API token charges, GitHub runner minutes, refund rate, churn and payment fees. Use static analysis first; BYO API key or metered AI credits for paid AI features.
