      Restore selected files?

      Guardian verifies the archived bytes and checks that each original path is absent before writing. If a path already exists at that check, restore stops. The browser cannot make the check and write atomic, so keep both folders unchanged. A verified archive copy is retained until you explicitly purge it.
        RECOVERY CHECK

        Reconcile verified archive entries?

        Guardian rechecks the stored SHA-256 and bytes. If the original source still exists and matches, it removes that source entry and updates the journal. If the source is already absent, Guardian records the verified archive without claiming who removed it.

          Keep both selected folders unchanged during this check. The verified archive is not removed.
